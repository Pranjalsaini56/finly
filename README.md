# Finly — AI Finance Controller

Finly is a personal finance management application built with Python,
Streamlit, Pandas, and Altair.

It helps users record income and expenses, automatically categorize
transactions, identify duplicate transactions, detect unusual spending,
and understand their financial activity through an interactive dashboard.

## Live Demo

🚀 [Open Finly](https://finly-finance.streamlit.app)

## Features

- Income and expense tracking
- Automatic transaction categorization
- Duplicate transaction detection
- Overspending detection
- Financial dashboard
- Income, expense, and balance calculations
- Interactive financial visualizations
- Transaction history
- CSV import/export
- Persistent local data storage
- Responsive dark-themed UI

## Tech Stack

- Python
- Streamlit
- Pandas
- Altair
